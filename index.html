연동 설정 · Firebase / Google Sheets

Code.gs 안내 · 복사해서 Apps Script에 붙여넣기
  1. Google Sheet를 만든 뒤 상단 메뉴 확장 프로그램 → Apps Script 열기
  2. 아래 코드 전체를 복사해 Code.gs에 붙여넣기
  3. 상단 배포 → 새 배포 → 유형: 웹 앱
  4. 실행 계정: 본인 / 액세스 권한: 모든 사용자 → 배포
  5. 발급된 웹앱 URL을 위 입력창에 저장
